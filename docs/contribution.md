# Contributing

The full contributor guide — finding something to work on, development
setup, branching, commit sign-off, the PR process, and how contribution
turns into repository access — lives at
[`../CONTRIBUTING.md`](../CONTRIBUTING.md). This page is a short pointer
for anyone browsing `docs/`, not a second copy.

## The short version

1. **Find something:** a [`good first issue`](https://github.com/mne03005-png/OpenVideoStudio/labels/good%20first%20issue),
   a [community track](COMMUNITY_TRACKS.md) that interests you, or open a
   [Discussion](https://github.com/mne03005-png/OpenVideoStudio/discussions)
   under Ideas if it's something new.
2. **Fork, branch from `main`, make your change, add tests.**
3. **Sign off your commits** (`git commit -s`) — this project uses DCO,
   not a CLA.
4. **Open a PR** using `.github/PULL_REQUEST_TEMPLATE.md`.

→ **Full guide:** [`../CONTRIBUTING.md`](../CONTRIBUTING.md)

## Other ways to contribute that aren't code

- **Documentation** — install-guide fixes, tutorials, translations. See
  `COMMUNITY_TRACKS.md`'s Documentation & Localization track.
- **Hardware reports** — ran this on a GPU/OS not listed in
  `HARDWARE.md`? [File a report](../.github/ISSUE_TEMPLATE/hardware_report.md) —
  real reports from real runs are what keep that matrix honest.
- **Research** — several community tracks (Character Consistency, in
  particular) are explicitly open to benchmarks, experiments, and papers,
  not only finished code.
- **Reviewing PRs** — you don't need Maintainer status to leave useful
  review comments; formal blocking approval requires Reviewer role or
  above, but anyone can comment. See `GOVERNANCE.md` for how that role
  progression works.

## Reporting a problem instead of fixing it

That's a contribution too. Use:

- [Bug report](../.github/ISSUE_TEMPLATE/bug_report.md) — something's broken
- [Feature request](../.github/ISSUE_TEMPLATE/feature_request.md) — an idea or a proposed community-track contribution
- [Model request](../.github/ISSUE_TEMPLATE/model_request.md) — support for a new LLM/image/video/TTS provider
- [Workflow share](../.github/ISSUE_TEMPLATE/workflow_share.md) — share a prompt/storyboard workflow that worked well
- Security issue? **Not a public issue** — see [`SECURITY.md`](../SECURITY.md).
